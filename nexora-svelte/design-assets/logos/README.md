# Language logos

Official artwork for the languages the courses use, collected on 2026-10-26.
Every file is unmodified. Licences and sources are listed per language.

This folder sits outside `static/` on purpose. Nothing here is deployed or
linked from the site. Publishing a mark is a separate decision with its own
licence and trademark requirements; the current course cards use typographic
marks instead.

| Language | Files | Source | Licence | Use on this site |
|---|---|---|---|---|
| Go | `go.svg`, `go-white.svg`, `go-gopher.svg` | [go.dev brand](https://go.dev/blog/go-brand/Go-Logo/SVG/), [gopher](https://go.dev/doc/gopher/) | Logo: trademark, permission needed. Gopher: CC BY 4.0 | Gopher is used; the logo is not |
| Rust | `rust.svg`, `rust-white.svg` | [rust-lang/rust-artwork](https://github.com/rust-lang/rust-artwork) | CC BY 4.0, plus trademark rules | Allowed with attribution |
| Zig | `zig.svg`, `zig-light.svg` | [ziglang/logo](https://github.com/ziglang/logo) | CC BY-SA 4.0 | Allowed with attribution and share-alike |
| OCaml | `ocaml.svg`, `ocaml-white.svg` | [ocaml/ocaml-logo](https://github.com/ocaml/ocaml-logo) | The Unlicense | Public domain |
| JavaScript | `javascript.png` | [voodootikigod/logo.js](https://github.com/voodootikigod/logo.js) | MIT | Allowed; Oracle owns the mark |
| SQL | none | No official logo exists | n/a | Keep the typographic "SQL" mark |
| APIs | none | No official logo exists | n/a | Keep the typographic "API" mark |

The white variants are for dark grounds; the main files are for light grounds.

## Files

- `go.svg` — official blue Go logo, 254.5 x 225.
- `go-white.svg` — official white Go logo.
- `go-gopher.svg` — official Go gopher bust by Renee French, line art.
- `rust.svg` — black Rust gear, 106 x 106.
- `rust-white.svg` — white-outlined Rust gear for dark grounds.
- `zig.svg` — Zig logomark and logotype, dark text for light grounds, 400 x 140.
- `zig-mark.svg` — Zig logomark alone, used in the course card.
- `zig-light.svg` — Zig logo for dark grounds.
- `ocaml.svg` — colour OCaml logo, 524.8 x 144.3.
- `ocaml-icon.svg` — colour OCaml camel icon alone, used in the course card.
- `ocaml-white.svg` — white OCaml logo for dark grounds.
- `javascript.png` — community JavaScript logo, 1052 x 1052.

Licence texts are saved beside the artwork: `go-LICENSE.md`,
`rust-LICENSE.md`, `zig-LICENSE.md`, `ocaml-LICENSE.md`,
`javascript-LICENSE.txt`.

## Attribution

If these marks are published, the page needs the credit the licences require:
Rust and Zig require attribution, and a modified Zig logo must carry the same
CC BY-SA 4.0 licence. Do not recolour or redraw a logo to fit a card.

The current course cards use the official marks for JavaScript, Rust, Zig,
OCaml and the Go gopher. The Go graphic logo is not published because its brand
rules restrict it on a commercial site. SQL and APIs use typographic marks
because they have no official logo. The gopher is cropped to its face by CSS,
so its footer credit notes the crop. Every other mark is shown unmodified.
